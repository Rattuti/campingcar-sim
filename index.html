    このアプリの数値の出典

    2026年10月19日に調べた内容です。法令は二次情報(解説記事)をもとにしているので、申請の前に国土交通省の通達の原文や運輸支局で確認してください。

    8ナンバー(キャンピング車)の構造要件

    • 就寝設備は乗車定員の3分の1(2022年4月から端数切り捨て。少人数の車は1名分で可)、大人180×50cm・子ども120×40cm、座席を倒しただけのものは不可。調理台85cm以下なら室内高120cmで可 — くるまのニュース
    • 給水・排水タンクはそれぞれ10L以上 — BE-PAL
    • 根拠の通達「キャンピング車等に係る構造要件等について」(2022年4月1日施行) — 行政書士事務所の解説 / 国土交通省 特種用途自動車のページ
    • 少人数の車の下限が「乗車定員3名以下」か「2名以下」かは記事によって書き方が違うため、このアプリでは「最低1名分」とだけ判定しています。

    ベース車の荷室寸法

    • ハイエース スーパーGL 標準ボディ: トヨタ公式カタログ(2021年7月) / キャラバン プレミアムGX: car-repo の比較記事
    • エブリイ・N-VAN: WEB CARTOP(2021年) — モデルチェンジで変わっている可能性あり

    車種・免許

    • 車種の分類・価格帯: グーネットマガジン / くるまのニュース(免許) / Jackery(ハイエースの価格帯)
    • 普通免許の区分(取得日で 3.5t未満 / 5t未満 / 8t未満)、けん引免許(被けん引車の総重量750kg超)は道路交通法の一般的な区分です。最新情報は警察庁・運転免許センターで確認してください。
